## When to use it

Read related project files in one workspace: Markdown documentation, nested JSON, CSV data, a PDF or an image. The file tree and tabs keep these files together. Ordinary UTF-8 text supports basic editing and automatic saving.

Markdown includes Mermaid diagrams and LaTeX formulas. JSON offers expandable trees, and CSV offers a table view with source access.

## Install

1. Open the latest Release page.
2. Choose the `-macos-arm64.dmg` installer for an Apple M-series Mac, or `-macos-x86_64.dmg` for an Intel Mac.
3. Open the DMG and drag Glim to Applications.
4. Current downloads are ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, follow the project's [first-launch instructions](https://github.com/NeoPanic/Glim#macos).

## Limits to know

- PDF, Office and image previews are read-only.
- Text editing is basic; Glim is not a full IDE or a spreadsheet editor.
- Large or long-line text may use read-only pages.
- Format support is not universal. See the [current format guide](https://github.com/NeoPanic/Glim/blob/main/docs/file-format-support.md).
