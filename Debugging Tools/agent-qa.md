<details>
<summary>⚙️ WHAT MAKES IT DIFFERENT?</summary>

- Describe a user journey in natural language and inspect its recorded evidence.
- Reuse facts and working procedures through persistent memidex memory.
- Validate lessons from runs and retire stale knowledge through self-improvement.
- Work through a CLI, dashboard, local MCP interface or coding-agent skills.

</details>

---

<details>
<summary>🧪 WHEN TO USE</summary>

Use for repeated web/mobile regression journeys and evidence-based failure triage.

Setup requires Node.js 24+, a configured model and test target; mobile testing
also needs Appium and a device or simulator. Model-provider charges may apply.
The runtime license is FSL-1.1-ALv2.

See the [official documentation](https://vostride.com/docs/agent-qa) and
[MCP guide](https://vostride.com/docs/agent-qa/mcp) for supported setup.

</details>

## 🚀 FINAL TAKE

A focused QA agent by vostride that combines persistent memory, recorded evidence
and validated self-improvement for web and mobile testing.
