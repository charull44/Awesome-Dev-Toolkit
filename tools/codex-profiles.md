<details>
<summary>⚙️ WHAT MAKES IT DIFFERENT?</summary>

<br>

codex-profiles is a dependency-free Bash wrapper that:

→ Gives each name its own `CODEX_HOME`<br>
→ Opens separate ChatGPT Desktop windows on macOS<br>
→ Keeps local state separate without copying tokens<br>
→ Supports macOS and Linux for CLI profiles

</details>

---

<details>
<summary>🧪 WHEN TO USE</summary>

<br>

Use when:

* Switching between personal, work, school, client, or test profiles
* Running Codex CLI commands against a specific named home
* Keeping multiple ChatGPT Desktop windows open side by side on macOS

</details>
